3. Requirement checklist — is the module implemented?

Coupons already existed in ShopSphere: admins could create percentage or fixed-amount codes with dates, a usage limit, a minimum order and a cap; customers could apply them in the cart and at checkout (one use each); admins could pause and edit them. Missing were product and category limits, a dashboard that separates active and expired coupons, and delete. Everything marked ADDED was built for this assignment.

4. End user documentation — Coupon and Discount Management

4.1 Coupon dashboard (admin)

Open Admin console → Coupons. The cards show how many coupons are active (and scheduled to start), expired (and used up), inactive or deleted, and the total discount customers received (cancelled orders excluded). The table lists each coupon's code and description, discount, minimum order, what it applies to, validity, uses (and discount given) and status. Use the filters (All, Active, Scheduled, Expired, Inactive, Used up, Deleted) and the search box.

StatusMeaning
ActiveSwitched on, started, not expired and uses left — customers can apply it
ScheduledSwitched on but the start date is in the future
ExpiredThe expiry date has passed
InactiveDeactivated by an admin (status = false)
Used upThe usage limit has been reached
DeletedSoft-deleted: hidden from the dashboard, kept for history, can be restored

4.2 Create or edit a coupon (admin)

  1. Click New coupon (or Edit on a row).
  2. Enter the code (4–30 letters or numbers, unique) and a description shown at checkout.
  3. Choose Percentage (%) (1–90%, with an optional maximum discount in ₹) or Fixed amount (₹), and the value.
  4. Optionally set Valid from, Expires and a Usage limit (total uses; empty = unlimited).
  5. Limits: a minimum order total, and optionally products (search and add) and categories (tap to select; subcategories are included). With products or categories chosen, the discount applies only to those items.
  6. Click Save coupon. A used coupon's code cannot be changed (create a new coupon instead).

4.3 Apply a coupon at checkout (customer)

  1. In the cart or at checkout (after choosing the address), type the code under Have a coupon? and click Apply.
  2. If the code is valid, it shows what you save and what it applies to, and Price details show Coupon CODE −₹… and the new total payable.
  3. If not, the reason is shown (expired, not started yet, used up, already used by you, minimum order not reached, or no eligible item in the cart).
  4. Remove takes the coupon off. The server checks the code again when the order is placed.

4.4 Deactivate or delete a coupon (admin)

  • Deactivate switches the coupon off (status = false): it stops working at once and shows as Inactive. Activate switches it back on.
  • Delete (bin button) asks for confirmation, then soft-deletes the coupon: it stops working, leaves the dashboard and appears under the Deleted filter with its history. Restore brings it back as inactive, so it can be checked before activating it again.

Appendix B: SQL behind each action

-- Create (and limit to a category)
INSERT INTO coupons (code, description, discount_type, discount_value, min_order_amount, max_discount,
                     valid_from, valid_until, usage_limit, used_count, active, created_at, updated_at)
VALUES ('BOOKS20', '20% off books — up to ₹300', 'PERCENT', 20, 0, 300, NULL, '2026-12-31 23:17', 500, 0, b'1', NOW(6), NOW(6));
INSERT INTO coupon_categories (coupon_id, category_id) VALUES (2, 12);
-- Dashboard status
SELECT code, CASE WHEN deleted_at IS NOT NULL THEN 'DELETED' WHEN valid_until < NOW() THEN 'EXPIRED'
                  WHEN active = b'0' THEN 'INACTIVE' WHEN valid_from > NOW() THEN 'SCHEDULED'
                  WHEN usage_limit IS NOT NULL AND used_count >= usage_limit THEN 'USED_UP' ELSE 'ACTIVE' END AS status
FROM coupons ORDER BY created_at DESC;
-- Deactivate / soft delete / restore
UPDATE coupons SET active = b'0' WHERE code = 'FLAT150';
UPDATE coupons SET deleted_at = NOW(6), active = b'0' WHERE code = 'HOME15';
UPDATE coupons SET deleted_at = NULL WHERE code = 'HOME15';
