4. End user documentation — Order Management

Order Management takes an order from the customer's cart to their door. Customers place, track and cancel orders; the ShopSphere administrator watches every order, moves it through its statuses and steps in when something goes wrong.

Order statuses. An order is Pending after it is placed (shown as Placed, then Confirmed and Packed while the seller prepares it), Shipped when it leaves the seller (then Out for delivery), and Delivered when the customer receives it. It becomes Cancelled if the customer or admin cancels it before it ships. Each item of an order also has its own status, because one order can contain products from different sellers.

Who uses it: customers place and cancel their own orders; only users with the Admin role see all orders and change their status. Sellers confirm and pack their own items; delivery partners record pickup and delivery.

4.1 Place an order (customer)

  1. Open a product and click Add to cart. Repeat for every product you want.
  2. Open Cart (top right). Change quantities or remove items; the cart shows the items total, delivery fee and amount to pay.
  3. Click Proceed to checkout.
  4. Address: choose a saved address or enter a new one, then click Deliver here.
  5. Review: check the items and, optionally, apply a coupon. Click Continue to payment.
  6. Payment: choose Pay online (Razorpay) or Cash on Delivery, then click Place order.
  7. Confirmation: the order number appears and an email confirmation is sent. The order is now Pending.

4.3 Update the order status (admin)

  1. Click View / update in the order's row. The order window shows its items (with each item's status and tracking), the totals with GST, the shipping address and the customer.
  2. Under Update order status, choose the new status in Move to, for example Shipped.
  3. Optionally type a Note for customer.
  4. Click Update status. A message confirms: Order … is now Shipped. The customer gets a notification and sees the new status and tracking number.

Statuses only move forward: Pending (Placed) → Confirmed → Packed → Shipped → Out for delivery → Delivered. The admin may skip steps, for example Pending → Shipped; the skipped steps are recorded automatically in the tracking history. When an order is shipped without a courier, ShopSphere Delivery is used with tracking number SSD-<item>. Cash on Delivery orders are marked paid when they are delivered.

4.4 Cancel an order (customer)

  1. Open My Orders and click the order.
  2. While nothing has been shipped, a Cancel order button appears at the top right. Click it.
  3. The window explains that all items go back into stock and that online payments are refunded (nothing is charged for Cash on Delivery). Click Yes, cancel order.
  4. The order shows Cancelled with the note Cancelled by customer. The sellers are notified.

Once any item has been shipped, the button disappears; the customer can return the item after delivery instead.

4.5 Cancel an order (admin)

  1. Find the order (the Pending filter lists every order that can still be cancelled) and click Cancel in its row, or Cancel order inside the order window.
  2. A warning window opens: the status becomes Cancelled, every item goes back into stock, online payments are refunded through Razorpay, the customer and sellers are notified, and the order is kept (soft delete) and cannot be reopened.
  3. Click Cancel order to confirm. A message confirms: Order … has been cancelled.

4.7 Frequently asked questions

Why is a cancelled order not deleted? Payments, refunds, stock and reports point to it. Cancelling sets its status to Cancelled and active to false, so it is hidden from active work but the history stays correct.

Why does the order say "Pending" on the dashboard but "Placed" elsewhere? They are the same: Placed is ShopSphere's name for a new order, and the dashboard groups Placed, Confirmed and Packed as Pending (not shipped yet).

Is GST added on top of the price? No. Prices already include GST; the "Includes GST (18%)" line shows how much of the total is tax.

Why does one order show items with different statuses? Each seller ships their own items. The order's status follows its least advanced item, so it is Delivered only when every item is delivered.

Is the customer told about status changes? Yes: every change creates a notification, and the order page updates live.

Can I reopen a cancelled order? No. The stock has been returned and any payment refunded; the customer places a new order.

Appendix B: SQL behind each action

The full, tested set is in DataBase/queries.sql, section 8.

-- Place an order: total = items - coupon + shipping; GST is inside the prices
SET @items    := (SELECT selling_price * 1 FROM products WHERE product_id = 62);
SET @shipping := (SELECT IF(@items >= free_shipping_threshold, 0, shipping_fee) FROM platform_settings LIMIT 1);
INSERT INTO orders (order_number, customer_id, status, active, subtotal, discount_amount, shipping_fee,
                    total_amount, tax_amount, payment_method, shipping_name, shipping_phone,
                    address_line1, city, state, pincode, created_at, updated_at)
VALUES ('SS261116-RN9V2C', 8, 'PLACED', b'1', @items, 0, @shipping, @items + @shipping,
        ROUND(@items * 18 / 118, 2), 'COD', 'Priya Sharma', '9000000010',
        'Flat 302, Lotus Residency, Kalyani Nagar', 'Pune', 'Maharashtra', '411006', NOW(6), NOW(6));

-- Order dashboard: order ID, customer name, shipping address, total and status
SELECT o.order_number, u.full_name AS customer_name,
       CONCAT_WS(', ', o.shipping_name, o.address_line1, o.address_line2, o.city,
                 CONCAT(o.state, ' ', o.pincode)) AS shipping_address,
       o.total_amount, o.status, o.active + 0 AS active
FROM orders o JOIN users u ON u.user_id = o.customer_id
WHERE o.status <> 'PENDING_PAYMENT'
ORDER BY o.created_at DESC LIMIT 10;

-- Filters
SELECT * FROM orders WHERE status IN ('PLACED','CONFIRMED','PROCESSING','PACKED');   -- Pending
SELECT * FROM orders WHERE status IN ('SHIPPED','OUT_FOR_DELIVERY');                -- Shipped
SELECT * FROM orders WHERE status = 'DELIVERED';                                    -- Delivered
SELECT * FROM orders WHERE active = b'0';                                           -- Cancelled

-- Update order status: Pending -> Shipped
UPDATE order_items SET item_status = 'SHIPPED', courier_name = 'ShopSphere Delivery',
       tracking_number = CONCAT('SSD-', order_item_id), shipped_at = NOW(6)
WHERE order_id = 14 AND item_status IN ('PLACED','CONFIRMED','PACKED');
UPDATE orders SET status = 'SHIPPED', updated_at = NOW(6) WHERE order_id = 14;

-- Cancel (soft delete) an order that has not shipped: stock back, status Cancelled, active = 0
UPDATE products p JOIN order_items oi ON oi.product_id = p.product_id
SET p.stock_quantity = p.stock_quantity + oi.quantity
WHERE oi.order_id = 15 AND oi.item_status IN ('PLACED','CONFIRMED','PACKED');
UPDATE order_items SET item_status = 'CANCELLED' WHERE order_id = 15 AND item_status IN ('PLACED','CONFIRMED','PACKED');
UPDATE orders SET status = 'CANCELLED', active = b'0', updated_at = NOW(6)
WHERE order_id = 15 AND status IN ('PLACED','CONFIRMED','PACKED');

The IDs are the ones in the local database used for the screenshots (order 14 = SS261116-P8Q68X, order 15 = SS261116-QPUHSU, customer 8 = Priya Sharma).
